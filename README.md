# Multi-Product Vending Machine

## Overview
Implemented an FSM-based multi-product vending machine in Verilog HDL supporting multiple product selections, coin-based payment, product dispensing, and change return.

## Features
- Multiple Product Selection
- Coin-Based Payment
- Product Dispensing
- Change Return
- Synthesizable RTL
- Verilog Testbench Included

## Tools Used
- Verilog HDL
- EDA Playground
